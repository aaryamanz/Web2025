GitHub Foundations

Proctored exam

Certification

03

The order I'd do them in

Quick wins first so you have momentum, then the exams. About a month of evenings, start to finish.

Right now, before anything else

Request the GitHub voucher

It's while supplies last. Takes five minutes once you're verified. Study for it later, but lock it in today.

This weekend

OpenAI + Anthropic

Two credentials, two of the biggest AI names, done in an afternoon. Add them to LinkedIn the same day.

Week 1

Snowflake badge 1

8–12 hours of hands-on labs. Do an hour or two a night. This also teaches you SQL patterns you'll use in technical interviews.

Week 2–3

GitHub Foundations exam

Work through both Microsoft Learn paths, then book it. Spend the most time on Git basics.

Week 3–4

Oracle OCI Foundations

Finish the free learning path and sit the exam. Confirm it still shows as free when you register.

04

How to list them

Put them in their own section, strongest first. Here's what it should look like.

Certifications & Courses
  • GitHub Foundations (GH-900) — GitHub2026
  • OCI 2026 Foundations Associate — Oracle2026
  • Hands-On Essentials: Data Warehousing — Snowflake2026
  • AI Fluency: Framework & Foundations — Anthropic2026
  • AI Foundations — OpenAI Academy2026

Proctored exams first, then the lab-graded badge, then courses. Same order on LinkedIn.

Do

Add each one to LinkedIn under Licenses & certifications with the credential link, so anyone can verify it in one click.

Do

Be ready to talk about one thing you learned from each. "I did the Snowflake labs, here's what I built" beats the line itself.

Don't

Call a course badge a "certification." Label OpenAI and Anthropic as courses. Recruiters notice, and honesty makes the real certs look stronger.

Don't

Let certs replace projects or experience. They're the tiebreaker that gets you a second look, not the main event.
